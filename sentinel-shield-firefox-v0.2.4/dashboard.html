How list importing works
The updater recognizes hosts-file entries and a useful subset of Adblock Plus syntax, especially domain-anchored rules, exceptions and some type-scoped rules. It does not implement every EasyList feature, scriptlet, redirect, procedural cosmetic rule or CSP directive. A reported list size is not a guarantee of complete upstream rule compatibility.
Sources: StevenBlack unified hosts (combined adware/malware sources), EasyList (ads), EasyPrivacy (tracking). These are third-party lists; review upstream content and licensing before redistributing this project. The update button contacts only those list URLs when explicitly pressed.

Adding a language in a fork
Copy en.json, keep the same English keys, translate the values, and save it as your-locale.json in mods/translate/. Then register the locale in background.js, localization.js and the language selector in Settings. Keep the JSON valid and do not add executable code to translation files.
Modding principles
Sentinel mods are deliberately plain text and JSON. Translation packs do not execute code, and the core engine does not load third-party JavaScript plugins. Forks can customize the interface, rules and localization while keeping changes easy to review.
